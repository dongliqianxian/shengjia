# WinOLS 截图分析技能（Visual Map Identification）

从一张截图读出比用户说出来的更多信息。本技能专门处理"只看图、
没有 bin、没有地址、没有定义文件"的常见场景，以及"我有截图也有地址
但不确定是什么表"的辅助场景。

---

## 1. 截图类型识别（先分类再分析）

截图类型决定了能提取什么信息、不能提取什么信息。

| 截图类型 | 截图特征 | 可提取信息 | 分析可信度 |
|---------|---------|-----------|----------|
| 3D 图形视图 | 彩色 3D 曲面，X/Y/Z 轴带刻度 | 曲面形态、Z 值范围、轴刻度、色阶分布 | 高 |
| Hex 窗口 | 十六进制字节 + ASCII 侧栏 | 地址、原始字节值、数据类型、数据连续性 | 很高 |
| 数值表格窗口 | 行列式数值排列，带标题 | 精确数值、行列数、缩放因子、单位 | 很高 |
| 2D 曲线 | X/Y 折线图，单线或多线 | 趋势、轴范围 | 中 |
| GRP 对比 | 原厂 vs 修改版对比，蓝色/红色增量色阶 | 修改幅度、修改区域、delta 值 | 高 |
| DAMOS 窗口 | MAP 名 + 地址 + 轴定义 + 描述 | 完整语义定义、地址、物理单位 | 很高 |
| 项目树 | 左侧导航树，列表形式 | 项目结构、ECU 平台、已识别 MAP 列表 | 中 |
| 轴编辑窗口 | X/Y 轴断点数值列表 | 轴断点（RPM/Load 等） | 高 |

## 2. 视觉形态分类（从 3D 图形判断 MAP 类型）

这是核心能力：从曲面形状反推 MAP 功能。

### 2.1 Torque Model / Load 类

| 形态描述 | 可能 MAP | 关键判据 |
|---------|---------|---------|
| 中部隆起、四周低：山丘形态，峰值在中等转速+中等负荷区域 | VE 表 / 标准扭矩 / 负荷请求 | 峰值通常在 2000-4000rpm 的中高负荷区，范围 50-120% Load 或 100-600 Nm |
| 高原状：中高转速区平坦或缓慢上升，接近 WOT 略微下弯 | WOT Torque Limit / 最大扭矩限制 | WOT 区域平顶或微降（保护性限扭） |
| 陡崖式下降：高转速或高负荷区突然跌落到接近零 | 扭矩限制器 / RPM Limiter / 保护扭矩 | 与正常扭矩曲面的差异是保护行为而非物理极限 |

### 2.2 Boost / WGDC 类

| 形态描述 | 可能 MAP | 关键判据 |
|---------|---------|---------|
| WOT 区隆起：只有 WOT 列高，其余区域全低 | Boost Target / 增压目标 | WOT 列 100-300 kPa，部分负荷接近大气压 |
| 中段高两端低：峰值在 2500-4500rpm WOT | Boost Target（涡轮特征） | 为涡轮效率区匹配 |
| 整体平缓增加：从低到高平滑递增 | Wastegate Duty / WGDC 基础 | 0-100% 范围 |
| 阶梯状：不同负荷区间有明显台阶 | 负荷相关 Boost Limiter | 各台阶对应不同限制级别 |

### 2.3 Spark / Ignition 类

| 形态描述 | 可能 MAP | 关键判据 |
|---------|---------|---------|
| 左上低、右下高：低负荷低转值低，随转速升高而升高，随负荷升高而降低 | 基础点火角 Base Spark | **点火角的标志性形态**；值通常 -5° ~ +45° BTDC |
| 高负荷区突然降低：WOT 高负荷区有明显凹陷 | 爆震控制 / Knock Retard | 高负荷区降低 3-8° 是刻意退点火 |
| 全区域异常偏高（>50°）或全区域偏低且平 | ECT/IAT 修正或传感器异常 | 不是基础点火表，是修正量或故障态 |
| 怠速区异常：800-900rpm 区域 10-20° | 正常点火怠速值 | 偏离此范围则怀疑 scaling 错误 |

### 2.4 Lambda / AFR / Fuel 类

| 形态描述 | 可能 MAP | 关键判据 |
|---------|---------|---------|
| WOT 区低谷：高负荷区数值明显低于巡航区（加浓） | Lambda 目标 / AFR 目标 | WOT λ 0.78-0.91；巡航 λ~1.0 |
| 全区域平坦接近 1.0 | 部分负荷 λ 目标 | ~0.98-1.02 波动是闭环目标 |
| 巡航区隆起：中负荷区域数值 > 1.0（稀薄） | 稀薄燃烧目标（仅直喷分层燃烧） | λ > 1.0 在稀燃发动机上正常 |
| 突变断层：某个工况突然加浓/变稀 | 催化保护 / 过热保护 | 通常伴有 ECT 或 EGT 条件触发 |

### 2.5 限制器 / 保护类

| 形态描述 | 可能 MAP | 关键判据 |
|---------|---------|---------|
| 全区域接近常数：整张表数值几乎不变 | 基础限值 | 必须与轴边界对比确认 |
| 高转速断崖：某个 RPM 后直接归零或极低 | RPM Limiter / 转速限制器 | 断点一般在 6500-7500rpm |
| 高负荷大梯度下降：高负荷区急剧下降 | EGT 保护 / 过热保护 / CAT 保护 | 条件触发的修正 MAP |
| 特定 RPM 的 U 型凹陷 | NVH 抑制 / 减震扭矩干预 | 凹陷通常在 1500-2000rpm 附近 |

### 2.6 VVT / Cam 类

| 形态描述 | 可能 MAP | 关键判据 |
|---------|---------|---------|
| 低转低负荷近 0、随转速/负荷递增 | VVT 进气目标 | 0-50° 范围，与负荷和 RPM 正相关 |
| 高转回落：高转速区 VVT 角度下降 | VVT 排气目标 / 进气回撤 | 为扫气或效率回落，5000rpm+ |
| 全区域 0 或固定值 | 该轴无 VVT 或 MAP 不存在 | 检查发动机是否配备 VVT |

## 3. 数值分布分析（从颜色/数值确认判断）

### 3.1 物理量范围匹配表

| 物理量 | 典型整数范围 | 与截图匹配特征 |
|--------|------------|-------------|
| 负荷 Load (%) | 0-200 | 轴上标签有 % |
| 扭矩 Torque (Nm) | 0-800 | 数值 50-600 之间 |
| 增压 (mbar abs) | 500-2500 | 四位数，怠速~1000 |
| 增压 (psi rel) | 0-30 | 小数值 +PSI |
| 点火角 (°BTDC) | -10~+60 | 可能有负值，低转低值 |
| Lambda λ | 0.7-1.5 | 包含 1.0 附近 |
| AFR (汽油) | 10-22 | 约 λ x 14.7 |
| 喷油量 (mg/stk) | 0-120 | 柴油常见 |
| WGDC / 节气门 (%) | 0-100 | 百分比 |
| 轨压 (bar) | 0-2500 | 柴油 |
| EGT (°C) | 0-1100 | 三位数，颜色偏暖 |
| VVT (°) | 0-50 | 单方向变化 |
| 温度 (°C) | -40~+150 | 包含负值 |
| Factor | 0-2.0 | 0.5-1.5 常见 |

### 3.2 色阶辅助判据

WinOLS 默认色阶：蓝（低）→ 绿 → 黄 → 红（高）

| 色阶分布 | 判读 |
|---------|------|
| 蓝色 > 70% | 大部分区域值低 → 限制器（未激活）或 Boost Target（仅 WOT 高） |
| 红色集中在特定区域 | 峰值集中区 = 发动机主工作区 |
| 红蓝对半 | 正常的两端分布 |
| 红蓝交界清晰 | 可能是阈值开启点 |
| 大面积橙红 | 数值偏高、检查 scaling 错误 |

## 4. 轴定义推测（从截图坐标推断）

### 4.1 X 轴（通常 = RPM）

| 观察特征 | 判读 |
|---------|------|
| 轴数值 600-7500 | RPM |
| 轴数值 1000-6500 | RPM，起始值 1000 |
| 非单调轴 | 不是 RPM，可能是 TPS / 档位 |
| 轴点分布不均 | 正常，RPM 断点密度在怠速/峰值扭矩区更密 |

### 4.2 Y 轴

| 观察特征 | 判读 |
|---------|------|
| 0-100 / 0-120 | 负荷 Load 或 TPS% |
| 200-1200 mbar | MAP（歧管压力） |
| 20-200 mg/stk | 喷油量（柴油） |
| 1-6 | 档位 |
| -10~+50° | IAT 或 Coolant 温度 |
| Y 轴数值 > X 轴 | Y 可能反转成了 RPM |

### 4.3 Z 轴

如果截图中有 Z 值标签（WinOLS 右上方 min/max），直接读取。
如果只有色阶，用颜色+已知 MAP 类型反推。

## 5. 截图分析输出格式

每次分析必须按以下结构输出，禁止模糊用语：

```
### 截图类型识别
- 视图类型：[3D/Hex/表格/2D/GRP/DAMOS/项目树/轴编辑]
- 平台特征：[ECU 品牌/型号推测]

### 视觉形态初判
- 曲面形态：[山丘/高原/陡崖/阶梯/平坦/U 型/断崖/其他]
- 与标准形态匹配度：[高/中/低]
- 推测 MAP 功能：[Torque Model / Boost Target / Base Spark / Lambda / VE / Limiter / VVT / WGDC / 修正]
- 可信度：[高/中/低]

### 数值分析
- 值范围：[min] ~ [max]，单位推测：[Nm / % / deg / lambda / bar / mg/stk / degC]
- 数据类型推测：[Uint8 / Int16 / Float32 / Uint16]
- scaling 推测：[factor/offset 反推值]
- 轴定义：
  - X 轴：[RPM/TPS/其他] [范围] [单位]
  - Y 轴：[Load/RPM/MAP/其他] [范围] [单位]
  - Z 轴：[物理量] [范围] [单位]

### 异常标志
- 数值超出合理范围：[是/否]
- 断层/突变：[位置和可能原因]
- 色阶异常：[饱和/过暗/单色]

### 交叉验证
- 与已知 ECU 该 MAP 的典型值对比：[一致/偏高/偏低]
- 建议对照的下一个 MAP：[名称/原因]

### 初判结论（视觉层，非最终判定）
- 最可能是什么表：[一句话] —— 可信度 [高/中/低] + 依据
- 疑似在链中的角色：[传感器/模型/执行器输出/限制器/修正]（**初判，待确认**）
- 需要补充的信息：[还需要什么才能定性]

### 移交
- 单表定性与"能否改/改多少" → `ecu-map-analysis`（**本技能不下修改结论**）
- factor/offset 与单位换算 → `winols-scaling-converter`
- 地址与字节读写 → `denso-bin-engine` / `bosch-conti-bin-engine`
```

> **本技能的硬边界**：截图只能给**视觉证据 + 可信度**，给不了定性。
> 分辨率低、色阶非标准、无 Z 值标签、无轴刻度时，一律明说"不可判、需要 X"，**不编造**。
> "能否修改 / 改多少"的结论一律由 `ecu-map-analysis` 出——这是 doctrine 的分工，不得越界。

## 6. 特殊场景：Hex 窗口分析

### 6.1 地址定位
- 截图中出现的地址（如 0x068AE8）→ 记录
- 注意 WinOLS 的地址模式：Segment:Offset 还是线性地址

### 6.2 数据类型推断

```
Int8:   -128~127，单字节
Uint8:  0~255，单字节
Int16:  -32768~32767，两字节
Uint16: 0~65535，两字节
Float32: 四字节，带小数精度
```

### 6.3 行列数确定
- 看 Hex 窗口列数设置（通常 8/16/32 字节每行）
- MAP 数据：看数值重复周期确定行列
- 轴数据：一维连续线性排列

### 6.4 地址连续性检查
- 连续地址 → 单张 MAP 或轴
- 地址跳变 → 多张表分段或指针表

## 7. 特殊场景：DAMOS 窗口分析

当截图是 WinOLS DAMOS 识别窗口时，提取：
- MAP 全名（OEM 命名）
- 地址（绝对地址）
- 行列数
- 轴定义及轴点数组地址
- 物理单位
- scaling 公式 factor/offset
- 层级关系

DAMOS 命名快速分类见 `damos-a2l-parser` 的 CHARACTERISTIC 解析与 `oem-strategy-library` 的跨平台 MAP 对照表。

## 8. 特殊场景：GRP 对比分析

| Delta 形态 | 可能的修改意图 | 风险评估 |
|-----------|-------------|---------|
| 全区域等比例抬升 | 整体加扭矩/点火/喷油 | 粗放，可能过度 |
| WOT 区抬升明显 | 追求峰值马力 | WOT 优化，常规 |
| 特定 RPM 抬升 | 针对性优化特定工况 | 精细调教 |
| 中低负荷抬升 | 优化日常驾驶响应 | 可驾驶性优化 |
| 不均匀随机分布 | 传感器噪声或错误修改 | 需要复查 |
| 轴断点改变 | 重新定义了 RPM/Load 轴 | 风险高，影响所有引用该轴的表 |

---

## 9. 常见误判陷阱

| 陷阱 | 真实情况 | 避免方法 |
|------|---------|---------|
| 高负荷低值 = 退点火 | 可能是 lambda 加浓（λ < 1 数值小） | 检查单位 |
| 大数值 = 扭矩 | 可能是 raw 值未换算 | 检查 scaling |
| 蓝色 = 不重要 | 蓝色区域可能是限制器激活区 | 限制器蓝色是未激活态 |
| 峰值 = 错误 | WGDC 峰值在 4000rpm 正常 | 结合发动机特性 |
| 形状像 = 同类 | Denso 和 Bosch 同功能 MAP 形态不同 | 平台特异性必须纳入 |
| 忽略轴单位 | Load% vs MAP mbar 判读完全不同 | 先确认轴定义 |

## 10. 与其他技能的交互

```
winols-screenshot-analyzer
├── 初步判断 MAP 角色 → ecu-map-analysis
├── 原始值换算 → winols-scaling-converter
├── 需要二进制地址 → denso-bin-engine / bosch-conti-bin-engine
├── 限制器/保护 MAP → stage1-calibration-matrix
├── DAMOS 名称识别 → oem-strategy-library
└── 所有结论必须经过 ecu-calibration-doctrine
```

## 11. 输出纪律

- 永远先判断截图类型，说明能提取什么信息
- 数值推断必须标明是推测
- 不确定时必须说需要补充什么信息
- 禁止"可能是扭矩相关"的模糊判断
- 颜色描述必须给出颜色到数值的对应
