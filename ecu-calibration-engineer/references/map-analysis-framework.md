## 快速判断流程

分析 Map 时先按证据强弱排序，不要只看软件翻译名称。

| 证据 | 可靠性 | 使用方法 |
|---|---:|---|
| Damos/A2L 原名 | 高 | 优先使用原始工程命名判断功能 |
| 相邻 Map 组 | 高 | 看同区域是否有同维度 limiter、target、correction |
| 坐标轴单位 | 高 | rpm、load、IQ、Nm、mbar、deg、lambda 直接决定功能范围 |
| Z 值范围 | 中高 | 判断是 Nm、mg/stk、mbar、deg、lambda、ratio、us |
| 数据形态 | 中 | 看是否平台化、递增、递减、修正型、保护型 |
| 软件中文翻译 | 低 | ECM/OLS/第三方 damos 名称可能翻译错 |

## 轴和单位识别

| 轴/值范围 | 可能含义 | 验证方法 |
|---|---|---|
| 600-7000 / 8000rpm | 发动机转速 | 与其他主表转速轴比对 |
| 0-100% | 踏板、负荷、节气门、Lambda 请求百分比 | 看 Z 值是否对应扭矩、开度、目标 |
| 20-1000Nm | 扭矩请求/限制/模型 | 与 Driver Demand、Torque Limiter 组比对 |
| 100-3000mbar | 增压/歧管压力/环境压力相关 | 看是否绝压，是否含 1000mbar 大气压 |
| 0-100mg/stk | 柴油喷油量或空气量 | 与烟度、轨压、喷油时间联动 |
| 0.65-1.20 lambda | Lambda 目标 | 汽油高负荷通常低于 1，柴油烟度边界通常大于 1 |
| 5-40deg | 点火提前角或 SOI | 看随转速/负荷变化方向 |
| 200-2500us | 喷油时间 | 通常以喷油量和轨压为轴 |

## 数据形态判断

| 数据形态 | 常见功能 | 工程含义 |
|---|---|---|
| 随踏板或负荷单调上升 | Driver Demand / Torque Request | 驾驶员请求转成扭矩或负荷 |
| 高负荷平台化 | Torque Limiter / Load Limiter | 最大允许输出边界 |
| 低转保守、中段释放 | 扭矩限制、增压目标 | 保护传动和涡轮效率 |
| 高转回落 | 空气效率、扭矩、点火、喷油保护 | VE 下降、排温或机械保护 |
| 低负荷接近 1.00，高负荷加浓 | Lambda Target | 高负荷冷却燃烧、保护催化器/活塞 |
| 随轨压增加喷油时间减少 | Injection Duration | 同油量下轨压越高喷油越短 |
| 随负荷增加点火减少 | Spark Advance | 抗爆震保护 |

## 控制链条定位

输出时必须说明：

1. 上游：这张表由踏板、模式、挡位、温度、海拔、保护状态中的哪些条件触发。
2. 本层：它是目标、限制、修正、转换模型还是监控边界。
3. 下游：它影响扭矩、负荷、增压、节气门、喷油、点火、换挡、油压中的哪一项。
4. 卡点：如果只改这张表，最可能被哪张表限制。

## 常见误判

| 表面名称 | 可能真实含义 | 注意点 |
|---|---|---|
| Air Flow | 可能是 load/filling，不一定是 MAF g/s | 看单位和轴 |
| Torque | 可能是模型、限制、请求、监控，不一定是目标扭矩 | 看是否有上限平台 |
| Lambda | 可能是 lambda、1/lambda、equivalence ratio | 高负荷方向能帮助判断 |
| Boost | 可能是绝压或相对压力 | 1000mbar 偏移必须确认 |
| Throttle | 可能是节气门目标、限制或扭矩干预 | 看是否超过 100 或受扭矩模型约束 |
| Injection | 可能是喷油量、喷油时间、SOI 或修正 | 看单位 mg/stk、us、deg |

## 输出检查清单

- 是否说明 Map 真实功能，而不是只翻译名称。
- 是否给出轴和 Z 值单位的可能性排序。
- 是否解释原厂设计目的。
- 是否定位到控制链条层级。
- 是否说明上游、下游、联动 Map 和卡点。
- 是否给出 Stage 1 / Stage 2 修改区域、方向和幅度。
- 是否明确哪些区域不动。
- 是否给出 LOG 验证项目和异常处理。
