# 怠速标定（定位 + 修改边界）

怠速在 ECU 里不是一个数，是**一套随工况变的目标转速 + 稳定控制**。找对了才谈得上改。

## 1. 怠速控制的结构（先建立心智模型）

| 标定项 | 形态 | 说明 |
|--------|------|------|
| **怠速目标 vs 水温**（主） | 1D 曲线 vs ECT | 冷车高、热车低→**随温递减**。这是首要定位目标 |
| 冷启动快怠速 | 曲线/标量 vs ECT + 时间 | 冷启动抬到 1000–1400，随温/时间衰减 |
| 挂挡怠速偏移（AT） | 偏移/单独曲线 | Drive 比 Neutral 低（防蠕动/负载） |
| 空调怠速偏移 | 偏移 | AC 压缩机负载，+50~150 rpm |
| 电负载/助力补偿 | 偏移 | 大灯/风扇/转向助力抬怠速 |
| 催化加热高怠速 | 曲线 | 冷启动抬怠速 + 延迟点火,给 CAT 快速升温 |
| **怠速稳定控制** | 点火/进气/喷油闭环 | 怠速点火 trim(拉/退点火保转速)、电子节气门怠速进气量(老件 IAC 占空) |

- **典型值**：汽油热车 600–900、柴油 700–850；冷启动 1000–1400。
- **柴油**：无节气门，怠速由**喷油量怠速调节器 + 目标怠速 vs ECT**控制；负载(空调/发电)时抬怠速。

> **改怠速点火前必读**：原厂怠速点火看着"很退"（如 5–10°）**通常不是保守，是扭矩储备**——
> ECU 故意多进气 + 退点火，把一块扭矩"压住"，负载突增（挂挡/开空调）时把点火拉回即可**秒补扭矩**，
> 不用等进气（点火是快通道，空气是慢通道）。原理见 `torque-model-builder` §4 扭矩储备。
> **把这个退角"优化"掉 = 拆掉了防熄火机制**，表现为挂挡/开空调掉速甚至熄火。
> 降怠速同理：必须留足点火 trim 余量与进气余量。

## 2. 无 A2L 定位（用共享引擎）

怠速目标是**落在怠速 RPM 带、随水温递减的短单调曲线**——有结构信号，比标量可靠。

**共享引擎 `value_locate.py` 的实际位置**：`<skills 根目录>/speed-limiter-removal/scripts/value_locate.py`
（怠速、限速、断油转速三处共用同一引擎，只有一份，不要复制）。用**绝对路径**调用，不要用相对路径——
相对路径只在当前工作目录恰好是某个技能目录时才成立。

```bash
# Windows 默认位置：
python "$HOME/.claude/skills/speed-limiter-removal/scripts/value_locate.py" \
       --bin ECU.bin --preset idle_rpm --curve
```

引擎多缩放×双字节序穷举，列出所有落 [500,1300] RPM 带、6–40 点、单调的 run。RPM 缩放常见
`u16 直存 / u16 ÷4 / u16 ÷8 / u8 ×40/×32/×50`——引擎已内置尝试。

**确认候选是"怠速目标"而非别的 RPM 表**（关键，别拿错）：
1. **X 轴必须是水温**（ECT，典型 -40…120°C）——不是转速轴、不是负荷轴。
2. 值域在怠速带、冷端高热端低。
3. 交叉验证：`ecu-map-analysis` 拆解该表角色；有 A2L/DAMOS 用 `damos-a2l-parser`（Bosch 常见
   `LLR`/`N_LL`/idle governor 类命名，exact 标签经 A2L，不凭空写死）。
4. 别混淆：断油转速(rev-limit,高转带)、换挡转速、风扇/表底转速也在 RPM 域——靠轴和值域区分。

## 3. 修改方向与风险边界

| 改动 | 效果 | 风险 |
|------|------|------|
| 抬热车怠速 | 更稳、发电/油压更足 | 油耗↑、Drive 蠕动↑、可能超电子节气门怠速权限 |
| 降热车怠速 | 静、省油 | **失速**(挂挡/开空调/大负载)、抖动、涡轮/柴油**油压不足**、发电不足、DPF 再生需要怠速稳定 |
| 改冷启动快怠速 | 冷车行为 | 降太多→冷车不稳/熄火、排放恶化、催化升温变慢 |

- **铁律**：降怠速必须留足**怠速点火 trim 权限 + 进气/喷油怠速调节余量**，否则闭环补不回来就抖/熄火。
- 挂挡/空调/电负载偏移要**同步核对**，只改基础目标会在带载工况失稳。
- 柴油/涡轮尤其注意**怠速油压**下限。
- 改完 checksum 交 `checksum-crc-engine`；字节读写交 `bosch-conti-bin-engine`/`denso-bin-engine`；
  整套动力方案（若顺带）交 `stage1-calibration-matrix`。

## 4. 与其他技能

定位候选(本技能 + value_locate.py) → 拆解确认(`ecu-map-analysis`) → 标签/地址(`damos-a2l-parser`/
`winols-ols-parser`，无定义则 `ghidra-tricore-disasm`) → 字节改写(bin 引擎) → checksum(`checksum-crc-engine`)。
故障码相关用 `dtc-locator`。所有结论受 `ecu-calibration-doctrine` 约束。
