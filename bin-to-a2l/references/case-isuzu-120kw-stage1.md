## ★ 跨变体 diff 不可行(推翻我之前的说法)

我曾说"同平台第二个 bin(不同功率变体)→ diff 直接指出哪些表定义功率"。
**这句话缺一个前提:必须是同一个 SW 版本。**

| 文件 | SW | 项目串 |
|---|---|---|
| 120 kW 老款 | `10SW056329` / `10SW080906` | `MD1CS089_CUPF_V300` |
| 130 kW(用户车) | `10SW100085` | `MD1CS089_RT99_V400` |

**已知 map 地址交叉验证:0/12 对得上。** 布局完全重排。

| 对比 | 差异字节 | 占比 |
|---|---|---|
| 120kW ORI vs 130kW ORI | 4,298,508 | **51.2%** |
| 120kW ORI vs 其 Stage1 | 4,364 | **0.052%** |

**跨 SW 版本的差异是一次 Stage1 的 985 倍。** 跨版本 diff 得到的全是重定位噪声,零信息量。

> **修正后的说法:diff 只在【同一 SW 版本】内有意义。** 要做变体对比,必须先确认两份文件
> 的 SW 号一致;不一致就只能各自独立走全链路,再比较**物理量**(mg/stk、hPa、Nm),不能比地址。

## ★ 空气/燃油配比:这份做得好

| 转速 | λ ORI | λ Stage1 | |
|---|---|---|---|
| 1200 | 1.034 | **1.041** | **比原厂还好** |
| 1400 | 1.078 | **1.090** | **比原厂还好** |
| 1600 | 1.224 | 1.162 | |
| 2600 | 1.458 | 1.340 | |
| 3600 | 1.513 | 1.367 | |

**最低 λ = 1.041 @1200 rpm,且优于原厂。**

原因:调教师在**低转把增压抬得特别狠**——1200 rpm `1850 → 2330 hPa(+26%)`、
1300 rpm `1740 → 2330(+34%)`,中高转只抬 +5~7%。**这正是"空气优先":
油加在哪里,气就先加在哪里。**

## 本案例发现并修复的两个脚本缺陷

### 缺陷 1:同一 data 地址被小的伪描述符覆盖(已修)

真实的 25×15 燃油上限(data `0x4B0354`)被一个伪造的 5×6 描述符顶掉,
`load_targets` 按 data 地址去重时**后者覆盖前者**,导致该图 689 字节改动变成"未归属"。

→ 修复:同一 data 地址**保留 cells 最大的那个**。
**覆盖率 15.4% 未归属 → 0.0%。**

### 缺陷 2:`cal_inventory` 只扫二维(已知限制,未修)

1D 曲线和标量扫不到。BJ40 只给 `--maps` 时,轨压限制曲线、全局扭矩标量、
最大扭矩曲线共 230 字节归属不了;补上 `--spec` 后 100% 覆盖。

→ **纪律:`stage_diff` 应同时给 `--maps`(二维全覆盖)和 `--spec`(曲线/标量 + 命名)。**
