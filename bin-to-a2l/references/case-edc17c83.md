# 参考案例:Bosch EDC17C83(ISUZU D-Max / V-Cross 1.9 RZ4E)

**第四个平台。** 本案例的价值有两点:①第一次在**没有厂商驱动**的情况下完成验证,
催生了"差分覆盖率作替代控制组"这个方法;②`flatten` 检测第一次抓到**成规模**的安全相关改动。

**文件**:2,097,152 字节(2 MB)× 2(ORI + Stage1),bench 读取。
**身份**(取自文件内字符串):`EDC17_C83` / SW `10SW0312151450V260` / 项目 `P1450V260F29P90` /
`833/1/EDC17_C83/26/P_1450//V260///` / **`RZ4EC8312V`**(证实 RZ4E 发动机)。
ORI 与 MOD 软件号一致 → 差分有效。

---

## ① 探针

```
A_hdr_XY_data   le  width2   2009    <- winner
B_hdr_swapped   le  width2   1922
E_hdr_YX_data   le  width2   1899
A_hdr_XY_data   be  width2     14    <- 错字节序对照组
```

**143.5x**。同一容器布局,与 MD1CS089 / EDC17C63 一致。

## ② 控制组:没有 ECM 驱动怎么办

本案例**没有 ECM Titanium 驱动**,拿不到已知地址做控制组。改用 ORI/MOD 差分覆盖率:

> 改动字节 7787,落在探针找到的描述符内 **7504 = 96.4%**

ABI 若判错,调教师改的字节不会这样整齐落进描述符。**96.4% 即为 ABI 正确的证据。**

**这个方法从此写进技能主流程**(SKILL.md §2.1.1)。

## ③ 这份 Stage1 的两个问题

### 问题 1:空气/燃油失衡,五份商业件里最差

| | 地址 | 倍率 |
|---|---|---|
| 燃油上限 | `0x0B32D6` 25×25(RPM × 压力) | **+22.2%**(4500→5500,uniform) |
| 空气侧 ×18 副本 | `0x0BA576` 等 16×16 | **+4.0%**(2851→2965,uniform) |
| **λ 比** | | **0.851 —— 全带一致下降 15%** |

油 +22%,气 +4%。

### 问题 2:8 张表被拍平或拉满

```
清零 (12000 → 0):   0x1F6F08 16x30 (480 格,原本有形状)
                    + 5 张同区域重叠的扫描伪影
拉满到 0xFFFF:      0x1F72F4 10x10  62942 → 65535
                    0x1F89A2  8x8    1455 → 65535
```

`0x1F89A2` 原本沿两轴**递减**(1112→229),改成全 65535 = u16 上限,
等于**触发条件永远不成立**。

**功能未能确认**:轴不匹配任何可识别物理量(X 13–300,Y 0–20000),地址在标定区末尾,
附近无可读命名串。"一个累积量清零 + 触发阈值拉满"的组合**形态上**符合关闭某个累积-触发类功能,
但**证明不了是哪一个,不得当事实陈述**。

要定性只有两条路:**A2L/DAMOS**,或 `ghidra-tricore-disasm` 找谁读这几个地址。

### 判定(按 `reference-tune-porting` 审计表)

| 改动 | 判定 |
|---|---|
| 燃油 +22.2% / 空气 +4.0% | **fix** —— 调到匹配 |
| 轨压 +3.3~4% | keep |
| `0x1D0256` 由成形(1158–2025)改成常数 3100 | **drop** |
| 6 张清零 + 2 张拉满 | **drop** —— 安全类拍平,且功能未确认 |
