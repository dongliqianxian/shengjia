# 参考案例:Bosch EDC17C63(JMC,TriCore)—— 第二平台验证

用途:证明容器 ABI 是**跨代 Bosch 约定**而非 MD1 特例,并记录本平台暴露的三个通用性缺口。

**文件**:1,572,864 字节(1.5 MB),bench 读取。
**身份**(取自文件内字符串,不是文件名):
`EDC17_C63` / SW `10SW0411171614V501` / 项目 `P1614C63FFCN5_V501`(`CN5` = 国五)

---

## 文件结构:标定区读取,不是全 dump

| 区间 | 内容 |
|---|---|
| `0x000000–0x01FFFF` | 全 `0xFF`(128 KB 空) |
| `0x020000–0x06F167` | **真实标定数据(约 320 KB)** |
| `0x06F168–0x07FF6B` | `0xC3` 填充 |
| `0x080000–0x17FFFF` | 全 `0xFF`(1 MB 空) |

**75.3% 是 0xFF**,且**没有代码区**。ECM 的 18 个地址全部落在 `0x020000–0x06C000`。
→ 这类文件反汇编路线天然无从谈起,结构路线是唯一选择。

## ① 探针结果

```
A_hdr_XY_data   le  width2   471    <- winner
B_hdr_swapped   le  width2   385
E_hdr_YX_data   le  width2   369
A_hdr_XY_data   be  width2     4    <- 错字节序对照组
```

**118x** 领先对照组。残留歧义与 MD1 完全一致(行列序、数据宽度)。

## ② 控制组:18/18

用 ECM Titanium driver `J24_01F7` 的 18 个地址逐个验证
`u16[data-(4+rows*2+cols*2)] == rows`:

**18/18 MATCH**,含一条 23×1 曲线(`[n][axis][data]` 形式)。

> **结论:EDC17C63 与 MD1CS089 用同一个容器布局。**
> TriCore 时代与 AURIX 时代通用 → 遇 Bosch 柴油先假设自描述。

## 本平台暴露的三个通用性缺口(已修入脚本)

### 缺口 1:喷油量单位是**体积**不是质量

EDC17 用 **mm³/Stk**,MD1 用 **mg/Stk**。差一个柴油密度 **0.832 mg/mm³**。
不折算会系统性高估 20%。→ `physics_check.py --units volume`

### 缺口 2:铭牌可能只有功率,没有扭矩

实测 JX4D24A5L 铭牌:额定功率 103 kW、最大净功率 101 kW,**无扭矩**。
→ `--nm` 改为可选,缺省时只用功率打分。

**但只用功率判别力弱得多**:本例前 4 名全是轨压图凑巧闭合(`0x06A7D2` 轨压限制 −0.4%、
`0x069E9E` 轨压 #5 −1.1%),真正的燃油上限反而没进前列。
→ **只有功率时,闸门只能验证"没有量级错误",不能用来认表。**

### 缺口 3:`physics_check` 只采样第 0 列

对二维燃油上限,第 0 列不一定是包络。本例 `QuantityLimiter_2/3` 的真实包络要按行取最大值。
→ 已知限制,认表时须手工按行取 max 复核。

## 闸门的分辨率极限(重要)

| η | 由燃油上限反算 | vs 103 kW(铭牌) | vs 92 kW(文件名 125hp) |
|---|---|---|---|
| 0.385 | 93.4 kW | −9.3% | **+1.5%** |
| 0.42 | 101.9 kW | **−1.1%** | +10.7% |

**两个候选额定值只差 12%,完全落在 η 假设的不确定带内 —— 闸门分不出。**

闸门能抓的是**量级错误**(缩放差 10 倍、字节序错、ABI 错),**不是 10% 级的变体差异**。
要分辨变体,需要 LOG 或同平台第二个 bin 做 diff。

## 附带发现:文件与车辆对不上

| 来源 | 说法 |
|---|---|
| 文件名 | JMC Baodian 2016 **2.9L** TD **125 hp**(≈92 kW) |
| ECM driver 标签 | JMC CARRYING **2400** 16v CRD **140CV**(≈103 kW) |
| 车辆铭牌 | JX4D24A5L **2402 mL**,额定 **103 kW** |
| 物理闸门 | 93.4 kW(η=0.385)~ 101.9 kW(η=0.42) |

driver 与文件 18/18 吻合(说明 driver 确实覆盖此文件),但 ECM driver 的标签是**族名不是车型**。
文件名与铭牌互相矛盾,闸门无法裁决。**这种情况下不应把 A2L 冠以某个车型名**——
本例 A2L 以 **SW 号**命名(`JMC_EDC17C63_10SW0411171614V501`),不写车型。
