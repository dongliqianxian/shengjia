# 扭矩模型静态储备分析与偏置设计 (torque-reserve-analyzer)

## 先说清能做到什么 (doctrine 诚实底线)

**做得到:** 给一对正/逆扭矩表, 逐格算出**表内储备图**(错位量)、**扭矩灵敏度图**
(dF/drl), 并按"目标储备山包"**用当地斜率精确反算**逆表偏置, 改完**闭环自证**
(新表的储备图 == 设计图)。全程不需要 A2L。

**做不到:** 判断上游 η储备 除数是否为 1(储备的另一个藏身处)、点火实际离 MBT 多远、
目标区是否压在爆震线上。这三件决定偏置**能不能兑现**, 只能靠:

| 缺口 | 去哪补 |
|------|--------|
| 上游 η储备/ETADZW 表在 bin 里哪 | `blind-map-finder` 盲扫 + `ecu-map-analysis` 判定 |
| 点火离 MBT / 爆震回退量 | OBD 实测: 空调阶跃法 / 爆震回退 PID / 换油对照 |
| 表字节解码 | bin 引擎 (本技能吃的是已解码 CSV) |

## 原理 (一屏讲完)

```
正模型 F (KFMIOP类): (rpm, rl%Air) → 扭矩%   "这些空气在MBT下能出多少"
逆模型 G (KFMIRL类): (rpm, 扭矩%) → rl%Air   "要这些扭矩得给多少空气"

表内储备(n,T) = F(n, G(n,T)) − T
  = 0   → 干净互逆, 零表内储备 (原厂常态, 储备走上游η除数)
  > 0   → 逆表多要空气 → 点火推迟吃掉 → 这就是储备(响应快,费油)
  < 0   → 逆表少要空气 → 扭矩不足, MBT也补不上 → 车更肉(新手坑)

偏置反算: dG(n,T) = 目标储备(绝对扭矩%) ÷ slope(dF/drl 在该工况点)
  中负荷 slope≈0.5 → "空气+5%≈储备+5%" 成立
  高负荷 slope≈0.35 → 同样储备要付1.5倍空气 → 山包高负荷侧必须收窄的定量理由
```

**代价换算(经验值):** 每 1% 相对储备 ≈ 1% 巡航油耗 ≈ 1.2~1.5° 点火推迟。
峰值上限 **6%**; >6% 推迟进入催化器加热量级(10°+), 且低转高负荷区可能撞爆震线兑现不了。

## 工作流

```
1. WinOLS 里两张表分别 复制→存 CSV (行=RPM, 列=各自轴, 左上角任意)
2. analyze  → 储备图(数据质量自检: 原厂表应≈0, 跳出的格子先查转录/解码!)
            → 灵敏度图(决定哪里加得起)
3. 拿灵敏度图定山包参数 → design → 得新逆表 CSV + 闭环验证报告
4. 三查: 闭环收敛<0.3绝对% / 每行单调 / 设计区外0偏置 —— 报告里自动给结论
5. 新表数值回填 WinOLS。装车前先过 OBD 三问(爆震回退=0? 空调阶跃点火跳提前?
   目标区rl离爆震带多远?) —— 表内结论成立 ≠ 车上兑现
```

## 命令

```bash
# 储备扫描 + 灵敏度图
python scripts/torque_reserve.py analyze --fwd F.csv --inv G.csv [--out report.txt]

# 设计山包偏置 (示例即 MG1US008 项目实际参数: 峰值+5%, 2000~3200rpm / 30~50%请求)
python scripts/torque_reserve.py design --fwd F.csv --inv G.csv \
    --rpm-lo 1200 --rpm-hi 4800 --t-lo 20 --t-hi 80 \
    --peak-rpm-lo 2000 --peak-rpm-hi 3200 --peak-t-lo 30 --peak-t-hi 50 \
    --peak 5.0 --out-inv G_new.csv

# 自检 (7 项断言, 改脚本后必跑)
python scripts/torque_reserve.py selftest
```

参数含义: `rpm-lo/hi, t-lo/hi` = 山包外沿(此外 0 偏置); `peak-*` = 平顶区;
外沿→平顶余弦渐变。`--peak` 单位为**相对储备%**(不是空气%——脚本按斜率换算成空气)。

## 读报告

- **储备图**: 原厂表全场 |x|<0.5 → 干净互逆 ✓。`*` 号格 = 逆表输出超正表 Air 轴,
  反演病态区(3% 低扭矩列和 90~100% 顶列常见), 结论不可信, 属正常现象。
  中低负荷若有 >0.5 的格: 先当**转录/解码错误**查, 排除后才是真·表内储备。
- **灵敏度图**: 找 slope 从 ~0.5 掉到 ~0.35 的转折带 → 山包 t-hi 别越过它。
- **偏置量图**: 每格实际 dG/G%, 直接对照回填; 注意它不等于 --peak(斜率修正过)。
- **闭环实得储备**: 必须与设计目标一致(报告自动判)。这是"改对了"的唯一证据。

## 铁律 (违反=返工)

1. **正模型 F 永远不改**——本技能只输出新逆表。F 是物理真值+CAN 上报来源,
   降 F = 低报扭矩 = TCU 夹紧力算错(烧片风险)+Level-2 监控风险。
2. 设计区外(怠速/低转/80%+ 高负荷/顶列)必须 0 偏置——脚本保证, 别手改。
3. 改完必须重跑 analyze 看新表储备图 == 设计图, 且每行单调。
4. 静态结论 ≠ 装车结论: 爆震线上的区域, 储备兑现不了, 只剩油耗。

## 跨车型判读经验 (实测积累: 长城炮 2.0T + 福特 Ranger, 均 MG1US008)

1. **两种参考扭矩标尺哲学**, analyze 前先认出是哪种:
   - 对齐型(长城炮): 正表 220air 处=100.000(0xFFFF 饱和), 逆表 100%列=正表轴顶。
     参考扭矩 = 轴顶空气能出的扭矩。
   - 超轴型(Ranger): 正表顶格只到 87~98(未饱和), 逆表 100%列要 224~254air(超正表轴
     10~15%)。参考扭矩定得比轴顶空气能出的高。→ 顶列 * 格是结构性的不是错误;
     90~100%请求区正表必然外插/钳位, 顶部扭矩上报精度打折; 须日志验证满增压实际 rl
     是否 >正表轴顶(是则 CAN 扭矩满负荷饱和)。
2. **低扭矩列储备信号判据**: 看沿转速的分布。转速局部化(如 Ranger 1000~1750rpm
   +9~14%相对, 1750 见峰 2000 骤降)=有意的表内怠速储备; 全转速均匀=低空气区曲率
   拟合噪声。验证: 怠速开空调看点火角跳不跳提前。
3. **负储备口袋(res<-0.5 非病态格)双解释**: ①转录/解码错误(优先查) ②原厂有意整形
   (增压门槛前防超调 / 排温预保护)。注意 design 会自动填平口袋再叠偏置——若口袋是
   错数, 该格新值也是错的, 查完须重新生成。
4. **增压门槛线**: 每行算 G 首次过 100air 的请求值(np.interp(100,G[i],t轴))。
   门槛随转速爬升(Ranger: 500rpm≈37% → 5000rpm≈50%)。峰值区右边界越过门槛越深,
   爆震三问越不能省。design 参数(rpm 网格/峰值区)必须按该车轴适配, 不可跨车照搬。
5. **储备单价随车不同**: 峰值区斜率 长城炮 mean 0.52 / Ranger mean 0.44 → 同样 5%
   储备 Ranger 多付 ~19% 空气。点火推迟量级只由储备%决定(~1.35°/%), 与空气无关。
