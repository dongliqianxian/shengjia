## 一、LOG 必看通道

按系统分组。**不是每次都要全开**——按当前处于黄金顺序哪一步选。

| 系统 | 通道 |
|---|---|
| **最低限度**（任何标定动作） | RPM、Load（计算负荷）、ECT（水温）、IAT（进气温）、λ（实测） |
| **空气** | MAP、MAF、Calculated Load、Cylinder Airmass（单缸空气量）、Throttle Position、IAT |
| **燃油** | Commanded / Measured Lambda、STFT（短期燃油修正）、LTFT（长期燃油修正）、Injector Pulse Width（喷油脉宽）、Injector Duty Cycle（喷油占空比）、燃油低压/高压 |
| **点火** | Final / Base Spark、Knock Retard（爆震减角）、Learned Knock（爆震学习值）、IAT/ECT Spark Correction |
| **扭矩** | Driver / Engine Requested Torque、Delivered Torque、Torque Limit Source（限制来源）、Throttle Intervention、Spark Torque Reduction |
| **增压** | Desired / Actual Boost、WGDC、Boost Error、Turbo Speed |
| **热管理** | ECT、IAT、EGT（排温）、CAT Temperature（催化器温度）、Component Protection Status |
| **怠速专用** | IAC 位置或占空比 / ETC 开度、怠速点火角摆幅 |

### LOG 结论必须回答

1. 是否爆震（区域 / 幅度 / 持续时间 / 气缸分布 / 重复性）
2. 是否有扭矩干预，来自 ECU 还是 TCU
3. 是否节气门被关闭
4. 燃油压力是否下降
5. 实际 λ 是否跟随目标
6. 空气模型是否偏差（用 STFT+LTFT 或开环 λ 误差判断）
7. 是否触发 EGT / CAT / 温度保护
8. 当前程序是否合理
9. 下一版应改什么
10. 下一次 LOG 需增加哪些通道

### 判读陷阱（Banish 明确点出的）

- **怠速点火摆动 10° 是正常的**（ECU 用点火快速调速）。**摆动 20–30° 通常指向负荷测量或转速信号精度问题**，不是燃油问题。很多小时浪费在用燃油修正去治点火问题上。
- **怠速脉宽异常大**通常指向别处的故障（某个传感器或修正曲线严重不对），不要当成「喷油器需要标定」。
- **WOT 占空比必须单独确认**。喷油器打满（静态）= 强制变稀，此时改任何燃油表都无效，只能加压或换喷油器。
- **闭环状态必须先确认**。已进闭环 = ECU 在用氧传感器修正，你看到的 λ 不代表基础表；未进闭环 = 基础表在直接决定喷油。

## 二、强制遗漏项检查清单（每次回答收尾必查）

> 原文档此清单有三条重复表述扭矩同步（ECU-TCU 一致 / Optimal-Inverse-Virtual 同步 / 监控模型同步），
> 已合并为一条三小项，避免检查时重复计数。

**扭矩链**
- [ ] TCU 档位扭矩上限是否匹配
- [ ] 扭矩模型同步性：① ECU↔TCU 一致　② 正/逆/虚拟扭矩同步　③ 扭矩监控模型（Level 2）同步
- [ ] Driver Demand（驾驶员需求）是否合理
- [ ] 传动系统保护是否在限制输出

**空气/燃油**
- [ ] MAP / MAF 是否超量程（pegging）
- [ ] 空气模型误差是否达标（< 5% 可接受 / < 3% 理想）
- [ ] VE 偏差是否导致 λ 漂移
- [ ] 喷油器是否接近占空比上限（> 85% 预警）
- [ ] 燃油轨压是否稳定

**点火/热**
- [ ] 爆震学习值是否需要清除或重学
- [ ] IAT 是否导致持续减点火
- [ ] EGT / CAT 热模型是否提前介入
- [ ] 使用工况（§9）与热标定是否匹配

**边界**
- [ ] 低转大扭矩是否超机械安全边界
- [ ] 高转区域是否保留原厂收敛趋势
- [ ] checksum gate：确认刷写设备会处理（不是手动重算）
- [ ] ORI 文件是否已保留、输出是否为新文件名

**元检查**
- [ ] 主动指出用户尚未提供、但可能影响结论的数据

## 三、增压 / 机械增压附加检查

**硬件容量**
- MAP / MAF 传感器量程（**红线：打满后不得靠改燃油点火继续加负荷**）
- 喷油器静态流量与死区、最大喷油占空比
- 燃油泵供给能力、高压油轨能力
- 中冷效率、进气温度
- 压缩比、燃油辛烷值、火花塞热值与间隙

**ECU 容量**
- 原厂扭矩模型量程（能不能表达 >100% 负荷）
- 原厂负荷模型上限
- 过压 / 超温保护逻辑
- 节气门关闭逻辑
- 变速箱允许扭矩

**离心式机增专项**
- [ ] 旁通/泄压气路是否绕过 MAF 上游（= 二次计量，MAF 无法标定）
- [ ] 旁通是否在 MAF 下游排大气（= ECU 以为进了气实际排掉 = 过浓）
- [ ] 低转区是否仍按自吸思路标定（离心机增低转几乎无增压）
- [ ] 驱动损耗（全负荷 30–50 hp 量级）是否计入燃油系统需求
- [ ] 峰值增压在红线附近 → 高转热负荷与爆震裕量是否复核

**容积式机增（Roots/TVS）差异**
- 低转即有增压 → 低转区不能按自吸思路标定，低转大扭矩的机械边界要先确认
- 扭矩曲线前移 → TCU 换挡扭矩与传动系保护更容易先撞上限
