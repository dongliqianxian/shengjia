## 通用纪律

**粗调在前，精修在后。** 建模阶段该用「电锯」——发现 MAF 曲线整体低 10%，就整条加 10%，
不要一格一格挪。精修阶段才用「砂纸」。

**反过来是最有价值的诊断信号**：如果到了融合/驾驶性阶段还需要大幅修改，
**说明前面的建模不对，或者车有硬件问题**。此时正确动作是回头查，不是在精修层继续打补丁。
（doctrine §1 原则 10）

**能拿到一份同硬件组合的已知良好标定，就从它改起。** 小改动比从零建表安全得多，
也不容易撞上无法启动的情况。

---

## ② 传感器与组件传递函数

发动机点着之前先做：钥匙 ON，对比 ECT、IAT、MAP 读数与环境实际值。
冷车静置一夜时 ECT ≈ IAT ≈ 环境温度；MAP ≈ 当地大气压。对不上就先修传感器/传函，不要往下走。

同时确认燃油压力已设定正确、ECU 里的喷油器参数与实际硬件和当前轨压一致。

---

## ④ 燃油交付建模（必须先于空气建模）

**为什么在前**：修空气模型的方法是「假定喷油量已知，则 λ 偏差全部归因于空气模型误差」。
喷油模型不准，这个假定就不成立，空气模型会把喷油器误差吸收进去。

需要进 ECU 的四项：

| 项 | 说明 |
|---|---|
| 静态流量 | 按实际轨压换算：`flow_actual = flow_ref × sqrt(P_actual / P_ref)` |
| 死区 / 开启延迟 vs 电池电压 | **是一条曲线，不是一个常数**。死区错了，怠速和小脉宽区最先崩 |
| 小脉宽非线性 | 低脉宽区流量不再线性的那一段 |
| 燃油系统容量 | `总 lb/hr ≈ 功率(hp) × BSFC(自吸 WOT ≈ 0.5)`；单喷油器 = 总量 ÷ 缸数；留 20% 余量（÷0.80）；泵同理 |

**稳态喷油占空比目标 < 85%。** 打满 = 强制变稀，此时燃油表怎么改都没用。

## ⑤ 空气流量建模（花最多时间的一步）

### 起手设置（四条，缺一不可）

1. **强制开环**。闭环的自修正会和你对着干，尤其在大凸轮、氧传感器位置改动过的车上。
   常见做法：把闭环使能表推到量程极端（开环最小节气门设 0%、闭环最低水温设到不可能的高值）。
2. **λ 目标拉平**。在你要标的整个区域设成同一个值（通常 λ=1）。
   目标是动的就等于在打移动靶，修正系数算不清。
3. **点火可以先锁死**，帮助稳定。
4. **从 1500 rpm 以上起步，先跳过怠速**。怠速是最难控的工况，留到 ⑦。

### 修正数学（λ 目标 = 1 时最简单）

```
修正系数 = 实测λ / 目标λ
新空气值 = 修正系数 × 旧空气值
```

目标 λ = 1 时，**修正系数就等于实测 λ**。这就是为什么要把目标拉平到 1。

- **MAF 车**：修的是 MAF 传函（电压/频率 → g/s）上对应那个断点的值。
- **速度密度车**：修的是 VE 表对应格子的值。

### 安全边界（建模阶段）

- 尽量不超过约 **60% 负荷**——这个范围能覆盖绝大多数格子，且温度可控。
- **过浓持续太久会洗缸**（冲掉缸壁油膜，伤活塞环）；**过稀会抬排温**，伤气门/排气歧管/三元。
- 水温异常或 λ 明显跑偏就停下来查，不要硬顶着继续。

### 无台架时的降级方案（我们的常态）

原方法要求锁定稳态点逐格修正。没有测功机时：

- **可以做**：定档位路试、稳住油门开度、等读数稳定后取点。同一档位改变油门开度即可扫过一片负荷区。
  平路巡航、缓坡、轻拖挂都能造出不同的稳态负荷点。
- **必须承认的损失**：拿不到完整网格 → **只能做整体缩放或分区缩放，不能重塑 map 形状**。
  凡是需要逐格重塑的结论，标注为「需台架」而不是硬给数字。
- **趋势外推是合法的省时手段**：如果已测的所有点都低 10%，就整条加 10% 一路到最大值，
  这会大幅减少后面 WOT 阶段的工作量。但外推区必须单独标记，不能当已验证。

### 验收

空气模型误差：**< 5% 可接受，< 3% 理想，< 1% 是原厂水平**。达标才往下走。

## ⑥ 部分负荷燃油与点火

燃油在前，点火在后。

**点火找 MBT（最佳扭矩点火角）的原理**：固定转速与负荷，加点火角直到扭矩不再上升（这就是 MBT）
或出现爆震，取两者中先到的那个。

- **轻负荷时 MBT 角度会看起来很大**——缸压低，燃烧慢，需要更多提前量。转速越高越明显。
  **不要被数字吓到**，但要确认扭矩确实在涨，并尊重爆震界限。
- **轻负荷过量点火很难把发动机搞坏**，所以部分负荷区可以放心向 MBT 靠。
- 没有测功机时无法直接看扭矩 → 降级为：按同平台/同软件的原厂趋势为基准，小幅试探 + 看爆震学习值与主观加速感，
  **并明确标注这是降级方法，精度不如台架**。

---

## ⑦ 怠速与低速稳定

- **怠速点火要故意退角，留出储备。** 如果怠速就在 MBT 上，负荷突然增加时 ECU 没有「加点火」这张牌可打，
  转速就掉下去了。这是原厂怠速点火看起来「保守」的真正原因，不是封印。
- 检查 IAC 位置 / ETC 开度：如果长期贴在全开或全关，说明节气门机械止点需要调整，
  控制器实际上没有调节余量。
- 大凸轮车 λ=1 怠速可能不稳，加最多 10% 燃油通常能改善（轻负荷下的小幅扭矩增加能稳定燃烧）。
  这类车巡航仍可 λ=1，但 tip-in 需要更多加速加浓。

## ⑧ WOT 燃油与点火

**前提**：⑥ 没做完就不要碰 WOT。跳过部分负荷直接调 WOT 的人，
后面在混合与驾驶性上要花掉更多时间，而且让发动机承受了不必要的高负荷试错。
发动机很少在低负荷坏掉——**高负荷阶段要争取用最少的次数试出正确设定**。

### 起手（保守优先）

- 点火先取一个**低于预期最大值**的安全角度。
- λ 目标先偏浓：**自吸 ≈ 0.85，增压 ≈ 0.77**。
- **把 50% 负荷以上的 λ 目标整片设成同一个 WOT 值**——低转时计算负荷可能偏低，
  拉平后修正数学才统一。
- 暂时关掉催化器保护加浓、活塞保护加浓等额外加浓项，标完再打开。
- **必须用宽氧**。窄氧（HEGO）在 WOT 目标区没有精度，只会误导。

### 修正

WOT 用扫描（sweep）而不是稳态——温度上得太快，撑不住稳态。
记录 RPM / MAF / MAP / 实测 λ，事后对比目标算修正系数，回代到空气模型的高流量段。

### 点火验收（无台架时的替代法）

原方法用扭矩曲线对比：跑两次不同点火角，看哪条扭矩曲线高，且两次都无爆震。
**没有测功机时**降级为：看爆震学习值、排温趋势、加速时间（可用 GPS/加速度计），
并明确标注为降级判据。

## ⑩ 瞬态与驾驶性融合

### 燃油表混合

建模期间 λ 目标是拉平的，现在要做过渡：
- 巡航区保持 λ≈1（排放与油耗）。
- **加浓从约 50–60% 负荷开始**向 WOT 目标过渡，中间用均匀台阶。
- **3D 看上去必须是光滑曲面。指令 λ 出现尖锐断层，通常是在掩盖别的问题**
  （加速加浓不够、或点火没标好）。
- 增压车：>100% 负荷区的目标，可参照同款自吸在 70–100% 负荷的目标来推。
  例：WOT 130% 负荷用 λ=0.80 的机增车，80% 负荷（≈100 kPa）仍应在 λ≈0.87 左右。

### 点火表混合

- 同样要求光滑。
- **机增车在约 80% 负荷时通常能接受和自吸版本一样的点火角。**
- 如果机增版静态压缩比更低，中低负荷反而需要**更多**点火角来补偿缸压不足。

### 加速加浓（AE）

- 目标：刚好补上油膜蒸发掉的那部分，不多给。
- 判据：定负荷 tip-in（如 15% → 50% 负荷，目标 λ 不变）时，**实测 λ 不应出现瞬时偏差**。
  瞬时变稀 = AE 不够（伴随「顿一下再走」）；瞬时变浓 = AE 过量。
- 凸轮越大，AE 需要越激进。全关节气门起步需要的 AE 最多（开度变化对应的面积变化最大）。
- 前提：静态空气与燃油建模已经做准。**AE 不是用来盖建模误差的。**

### Tip-in 点火

- 突然加载可能引发 burst knock（突增负荷时的瞬时爆震），即使稳态同点不爆震。
- 原厂常故意压瞬时扭矩上升率来降低传动系冲击噪音。要极致响应可以把这个退角设为 0，
  但要接受传动系间隙冲击的声音和寿命代价。
- 也可以用多加一点 AE 来压住轻微爆震，从而保住点火角和扭矩。

## ⑪ 闭环回归与收敛验证

- 放回闭环。如果 ⑤ 做到位，切回闭环不应该显著改变发动机表现。
- **把 STFT+LTFT 折回 VE/MAF**：`修正 = 1 + (STFT+LTFT)/100`，折回后修正量应塌到 **< 3%**。
- **修正量一直很大 = 基础模型仍然错**（或有未计量漏气、喷油器误差）。
  **不要用「放宽修正权限」来解决**——那是把问题藏起来。
- 往返自检（扭矩模型场景）：`air = G(t,n) → t2 = F(air,n)`，误差 < 3% 才算自洽。
  逆解落在正表轴外的点，误差不计入统计但必须单独标记。
